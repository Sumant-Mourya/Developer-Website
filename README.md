# Developer-Website

Publisher pages for my Android apps, served over GitHub Pages.

## Contents

| File | Purpose |
|---|---|
| `index.html` | Privacy policy for **Recline**, a call-recording app for Android |
| `app-ads.txt` | AdMob publisher verification, required by the IAB `app-ads.txt` standard |

## Live

<https://sumant-mourya.github.io/Developer-Website/>

This URL is referenced from the app's Play Store listing, so the repository name
and paths are load-bearing — renaming either breaks the store link and AdMob
verification.

## Editing

`index.html` is a single self-contained page with inline styles and no build
step. Edit and push; GitHub Pages redeploys from `main` automatically.
